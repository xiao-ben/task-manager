是什么

黄金不产现金流，定价更接近货币信用、实际利率和避险需求。

适用

宏观配置、通胀 / 信用对冲、危机定价。

选成长股、判断一家公司好不好、短期择时。

黄金的底层逻辑是什么？我拿它当判断框架，不是要预测价格。
先把它看成「不产现金流的货币信用影子」。能解释它的，通常是实际利率、美元信用和避险需求，而不是公司质地。用来判断「我在对冲什么」，不要用来判断「明天涨不涨」。
那和机会成本怎么一起用？
问第三句：这笔钱不买黄金会去哪，预期差够不够。两问都过，再动仓。
